# Resume Builder

## Описание

Resume Builder - это веб-приложение для создания и редактирования резюме. Приложение позволяет пользователям создавать профессиональные резюме с возможностью настройки различных разделов, выбора шаблонов и экспорта в формат PDF.

## Структура проекта

- `index.html` - основная HTML-страница приложения
- `main.js` - основной JavaScript-файл с логикой приложения
- `style.css` - файл стилей приложения
- `tests.html` - файл с тестами для приложения
- `README.md` - данный файл документации

## Функции приложения

### Основные возможности

- Редактирование личной информации (имя, должность, контакты)
- Добавление и удаление разделов:
  - Опыт работы
  - Образование
  - Навыки
  - Языки
  - Проекты
- Загрузка фотографии профиля
- Выбор из нескольких шаблонов (Современный, Классический)
- Настройка ориентации PDF (портретная, альбомная)
- Сохранение и загрузка резюме
- История изменений
- Генерация PDF-файла
- Мобильная адаптация (меню гамбургер для экранов до 425px)

### Интерфейс

- Верхнее меню с кнопками:
  - "Мои резюме" - управление сохраненными резюме
  - "Советы" - полезные рекомендации по созданию резюме
  - "История" - история изменений
  - "Скачать PDF" - экспорт в PDF
  - "Контакты" - контактная информация
- Боковая панель редактирования
- Центральная область для редактирования разделов
- Правая панель предварительного просмотра

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Библиотека html2pdf.js для генерации PDF
- Библиотека Sortable.js для перетаскивания элементов

## Запуск приложения

1. Откройте файл `index.html` в веб-браузере
2. Начните редактировать информацию в левой панели
3. Просматривайте результат в правой панели предварительного просмотра
4. Используйте кнопки в верхнем меню для дополнительных функций

## Тестирование

Для тестирования приложения используйте файл `tests.html`, который содержит автоматические и ручные тесты для проверки функциональности.

## Адаптивность

Приложение адаптировано для мобильных устройств:
- При ширине экрана до 425px отображается меню гамбургер
- Кнопки и элементы управления адаптируются под мобильные экраны
