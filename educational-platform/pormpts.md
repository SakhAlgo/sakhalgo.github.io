Задача: Реализовать систему тематических модулей, где каждая тема содержит от 1 до 5 заданий.

Требования:

Структура темы:

Каждая тема (например, "Заголовок страницы") должна включать от 1 до 5 заданий на одну и ту же тему

Темы должны группировать задания логически (например, все задания по работе с заголовками h1-h6)

Визуализация:

Пользователь видит сетку из карточек/квадратов, каждая из которых представляет собой задание

Каждая карточка содержит:

Номер задания (например, "#001")

Название задания (например, "Заголовок H1")

Индикатор сложности (звёздочки)

Состояния карточек:

Не выполнено — обычный стиль (серый/нейтральный)

Выполнено — зелёное свечение/подсветка (зелёный border или фон)

Активно — выделение текущей темы

Функционал:

При клике на карточку открывается соответствующее задание

После успешного выполнения задания карточка окрашивается в зелёный цвет

Прогресс сохраняется в localStorage

При повторном посещении темы карточки показывают актуальный статус

Технические детали:

Использовать существующую структуру 

task-manifest.js

 для определения тем

Добавить поле topic в конфигурацию заданий

Реализовать рендеринг темы в отдельном компоненте или секции

Сохранять прогресс через 

StorageManager

Использовать CSS-переменные для стилизации (зелёный цвет: var(--success))

Пример структуры данных:
