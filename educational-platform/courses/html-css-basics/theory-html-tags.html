📚 HTML теги

1. Что такое HTML?

HTML (HyperText Markup Language) — язык разметки для веб-страниц. Страница состоит из тегов — команд, которые говорят браузеру, как отображать содержимое.

<тег>содержимое</тег>

Большинство тегов парные: открывающий <тег> и закрывающий </тег>.

2. Заголовки (h1-h6)

Заголовки создают иерархию текста. <h1> — самый важный, <h6> — наименее важный.

<h1>Главный заголовок</h1>
<h2>Заголовок раздела</h2>
<h3>Подзаголовок</h3>
💡 Важно: На странице должен быть только один <h1>. Заголовки должны идти по порядку, без пропусков.

3. Абзац (<p>)

Тег <p> создаёт абзац текста. Браузер добавляет отступы между абзацами.

<p>Это первый абзац.</p>
<p>А это второй абзац.</p>

4. Форматирование текста

<strong> и <b> — жирный текст

<strong>Важный жирный текст</strong>
<b>Просто жирный текст</b>

<em> и <i> — курсив

<em>Важный текст курсивом</em>
<i>Просто курсив</i>

<br> — разрыв строки

Тег <br> переносит текст на новую строку. Это одиночный тег (без закрытия).

<p>Строка 1<br>Строка 2</p>

5. Списки

Маркированный (<ul>)

<ul>
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

Нумерованный (<ol>)

<ol>
  <li>Первый шаг</li>
  <li>Второй шаг</li>
</ol>

6. Изображения (<img>)

Тег <img> вставляет изображение. Атрибуты: src (путь) и alt (альтернативный текст).

<img src="cat.jpg" alt="Милый кот">

7. Ссылки (<a>)

Тег <a> создаёт гиперссылку. Атрибут href указывает адрес.

<a href="https://example.com">Нажми меня</a>
