🎨 CSS стилизация

1. Что такое CSS?

CSS (Cascading Style Sheets) — язык для стилизации HTML-элементов. С помощью CSS можно задавать цвета, размеры, шрифты, отступы и многое другое.

Базовый синтаксис CSS:

селектор {
  свойство: значение;
}

2. Цвет текста (color)

Свойство color задаёт цвет текста элемента.

p {
  color: red;        /* по названию */
  color: #ff0000;    /* HEX-код */
  color: rgb(255, 0, 0); /* RGB */
}

3. Фон элемента (background)

Свойство background задаёт фон. Можно указать цвет, изображение или градиент.

div {
  background: lightblue;
  background: #f0f0f0;
  background: url('bg.jpg');
}

Для фона также есть background-color — только цвет без других настроек.

4. Размеры (width, height)

width — ширина элемента, height — высота.

.block {
  width: 300px;
  height: 150px;
  background-color: #ffcc00;
}

Единицы измерения: px (пиксели), %, em, rem, vw, vh.

5. Отступы (margin, padding)

margin — внешний отступ (расстояние между элементами).

padding — внутренний отступ (расстояние от границы до содержимого).

.card {
  margin: 20px;        /* со всех сторон */
  margin: 10px 20px;   /* верх/низ лево/право */
  padding: 15px;
  padding: 5px 10px 15px 20px; /* верх право низ лево */
}

6. Граница (border)

Свойство border дбавляет рамку вокруг элемента.

.box {
  border: 2px solid black; /* толщина стиль цвет */
  border: 3px dashed red;
  border: 1px dotted blue;
}

Стили границ: solid (сплошная), dashed (пунктир), dotted (точки), none (нет).

7. Шрифт (font-family, font-size)

font-family — задаёт шрифт текста. font-size — размер шрифта.

p {
  font-family: Arial, sans-serif;
  font-size: 18px;
}

8. Выравнивание текста (text-align)

Свойство text-align выравнивает текст по горизонтали.

h1 {
  text-align: center;  /* по центру */
  text-align: left;    /* по левому краю */
  text-align: right;   /* по правому краю */
}

9. Прозрачность (opacity)

Свойство opacity задаёт прозрачность элемента от 0 (полностью прозрачный) до 1 (непрозрачный).

.faded {
  opacity: 0.5; /* полупрозрачный */
}
.invisible {
  opacity: 0;   /* невидимый */
}

10. Тень (box-shadow)

Свойство box-shadow добавляет тень к элементу.

.card {
  box-shadow: 5px 5px 10px rgba(0,0,0,0.3);
  /* смещениеX смещениеY размытие цвет */
}

11. CSS-селекторы

Селекторы указывают, к каким элементам применять стили.

Селектор по тегу

p {
  color: blue; /* все абзацы */
}

Селектор по классу

.my-class {
  font-size: 20px; /* все элементы с class="my-class" */
}

В HTML класс указывается так: <div class="my-class">

💡 Важно: В CSS перед именем класса ставится точка ., а в HTML атрибут class пишется без точки.

Селектор по ID

#header {
  background: black; /* элемент с id="header" */
}
