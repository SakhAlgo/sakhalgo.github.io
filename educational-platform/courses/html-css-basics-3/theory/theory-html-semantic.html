🎨 Семантические теги HTML

1. Что такое семантическая вёрстка?

Семантические теги описывают смысл содержимого, а не просто его внешний вид. Браузеры, поисковые системы и скринридеры лучше понимают структуру страницы.

💡 Важно: Семантические теги не меняют внешний вид страницы, но делают код более понятным и доступным.

2. header — шапка страницы

Тег <header> задаёт вводную часть (шапку) страницы или раздела. Обычно содержит логотип, заголовок, навигацию.

<header>
    Заголовок страницы
    Навигация
</header>
💡 Совет: На странице может быть несколько header — один для всей страницы и по одному внутри каждого section/article.

3. footer — подвал страницы

Тег <footer> задаёт нижнюю часть (подвал) страницы или раздела. Обычно содержит копирайт, контакты, ссылки.

<footer>
    <p>© 2024 Все права защищены</p>
</footer>

4. main — основной контент

Тег <main> содержит уникальное содержимое страницы. На странице один тег main.

<main>
    <p>Основной текст страницы</p>
</main>
💡 Важно: main не вкладывают в header, footer, article, aside, nav. Он один на страницу.

5. section — раздел

Тег <section> группирует связанный контент. Обычно внутри есть заголовок.

<section>
    <h2>О нас</h2>
    <p>Текст раздела</p>
</section>

6. nav — навигация

Тег <nav> содержит навигационные ссылки. Обычно внутри список <ul> со ссылками <a>.

<nav>
    <ul>
        <li><a href="#">Главная</a></li>
        <li><a href="#">О нас</a></li>
        <li><a href="#">Контакты</a></li>
    </ul>
</nav>

7. Типовая структура страницы

<body>
    <header>...</header>
    <nav>...</nav>
    <main>
        <section>...</section>
        <section>...</section>
    </main>
    <footer>...</footer>
</body>
