🛠️ Продвинутый CSS

1. Специфичность (вес) селекторов

Когда к элементу применяются несколько правил, побеждает самое специфичное. Вес считается как трёхзначное число (0,0,0):

СелекторВесПример
Тег (p, div, h1)(0,0,1)p { color: blue; }
Класс (.text)(0,1,0).text { color: green; }
ID (#main)(1,0,0)#main { color: red; }
Какой цвет победит?

Применится #main { color: red; } — у id самый высокий вес.

2. Наследование свойств

Некоторые CSS-свойства наследуются от родителя к потомкам. Например, color и font-family.

div { color: navy; font-family: Arial; }
/* p внутри div унаследует эти стили */


    
Наследованный стиль
💡 Важно: Не все свойства наследуются. Например, margin, padding, border — не наследуются.

3. Группировка селекторов

Если несколько селекторов должны иметь одинаковые стили, их перечисляют через запятую.

h1, h2, h3 {
    color: darkblue;
    font-family: Arial;
}
/* Все заголовки h1, h2, h3 будут темно-синими */

4. Псевдокласс :hover

Псевдокласс :hover применяет стили при наведении мыши на элемент.

button {
    background: lightgray;
}
button:hover {
    background: green;
    color: white;
}

5. Псевдокласс :first-child

:first-child выбирает первый дочерний элемент среди siblings.

li:first-child {
    font-weight: bold;
    color: darkred;
}
/* Первый пункт списка будет жирным и красным */

6. Псевдокласс :last-child

:last-child выбирает последний дочерний элемент среди siblings.

li:last-child {
    color: green;
    font-weight: bold;
}
/* Последний пункт списка будет зелёным и жирным */

7. Псевдоэлементы ::before и ::after

Псевдоэлементы добавляют виртуальный контент до или после элемента. Обязательно свойство content.

.quote::before {
    content: "«";
    color: gray;
}
.quote::after {
    content: "»";
    color: gray;
}

Текст цитаты

/* Результат: «Текст цитаты» */
💡 Важно: Без content псевдоэлемент не отобразится.

8. Единицы измерения px и %

ЕдиницаТипОписание
pxАбсолютнаяФиксированный размер в пикселях
%ОтносительнаяПроцент от родительского элемента
.parent {
    width: 400px;   /* фиксированная ширина */
}
.child {
    width: 50%;     /* 50% от 400px = 200px */
}

9. Flexbox — display: flex

Flexbox — одномерная раскладка. display: flex превращает контейнер в гибкий, и его дочерние элементы встают в ряд.

.container {
    display: flex;
    gap: 10px;
}
.item {
    flex: 1;  /* все элементы равной ширины */
}

10. Flexbox — flex-direction

flex-direction задаёт направление осей:

ЗначениеНаправление
rowСлева направо (по умолчанию)
columnСверху вниз
row-reverseСправа налево
column-reverseСнизу вверх
.container {
    display: flex;
    flex-direction: column; /* элементы в колонку */
}
