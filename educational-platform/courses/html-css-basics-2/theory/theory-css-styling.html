🎨 CSS стилизация

1. Что такое CSS?

CSS — язык для стилизации HTML-элементов. С помощью CSS задают цвета, размеры, шрифты, отступы и другое.

селектор {
  свойство: значение;
}

2. Цвет текста (color)

Свойство color задаёт цвет текста.

p { color: red; }
p { color: #ff0000; }
p { color: rgb(255, 0, 0); }

3. Фон (background)

Свойство background задаёт фон элемента.

div { background: lightblue; }
div { background: #f0f0f0; }

4. Размеры (width, height)

width — ширина, height — высота элемента.

.block {
  width: 300px;
  height: 150px;
  background: #ffcc00;
}

5. Отступы (margin, padding)

margin — внешний отступ (между элементами). padding — внутренний отступ (от границы до содержимого).

.card {
  margin: 20px;          /* со всех сторон */
  margin: 10px 20px;     /* верх/низ лево/право */
  padding: 15px;
  padding: 5px 10px 15px 20px; /* верх право низ лево */
}

6. Граница (border)

Свойство border добавляет рамку: border: толщина стиль цвет;

.box { border: 2px solid black; }
.box { border: 3px dashed red; }
.box { border: 1px dotted blue; }

Стили: solid (сплошная), dashed (пунктир), dotted (точки).

7. Шрифт (font-family, font-size)

font-family — шрифт, font-size — размер.

p {
  font-family: Arial, sans-serif;
  font-size: 18px;
}

8. Выравнивание текста (text-align)

text-align выравнивает текст по горизонтали.

h1 { text-align: center; }
h1 { text-align: left; }
h1 { text-align: right; }

9. Прозрачность (opacity)

opacity — прозрачность от 0 до 1.

.faded { opacity: 0.5; }
.hidden { opacity: 0; }

10. Тень (box-shadow)

box-shadow добавляет тень: смещениеX смещениеY размытие цвет

.card {
  box-shadow: 5px 5px 10px rgba(0,0,0,0.3);
}

11. CSS-селекторы

По тегу

p { color: blue; } /* все <p> */

По классу (.имя)

В HTML: <p class="note">. В CSS: .note с точкой.

.note { font-size: 20px; }
💡 Важно: В CSS перед классом ставится точка ., в HTML атрибут class пишется без точки.

По ID (#имя)

В HTML: <div id="header">. В CSS: #header с решёткой.

#header { background: black; }

Комбинированные селекторы

Можно комбинировать тег и класс: p.note — только <p> с классом note.

p.note { color: green; } /* только <p class="note"> */
