📚 HTML теги

1. Что такое HTML?

HTML — язык разметки веб-страниц. Страница состоит из тегов — команд для браузера.

<тег>содержимое</тег>

Большинство тегов парные: открывающий <тег> и закрывающий </тег>.

2. Заголовки (h1–h6)

Создают иерархию текста. <h1> — самый важный, <h6> — наименее важный.

<h1>Главный заголовок</h1>
<h2>Заголовок раздела</h2>
<h3>Подзаголовок</h3>
💡 Важно: На странице один <h1>. Заголовки идут по порядку, без пропусков.

3. Абзац (<p>)

Тег <p> создаёт абзац. Браузер добавляет отступы между абзацами.

<p>Первый абзац.</p>
<p>Второй абзац.</p>

4. Форматирование текста

Жирный: <strong> и <b>

<strong>Важный текст</strong>
<b>Просто жирный</b>

Курсив: <em> и <i>

<em>Важный курсив</em>
<i>Просто курсив</i>

Разрыв строки: <br>

Одиночный тег (без закрытия). Переносит текст на новую строку.

<p>Строка 1<br>Строка 2</p>

5. Списки

Маркированный (<ul>)

<ul>
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

Нумерованный (<ol>)

<ol>
  <li>Шаг 1</li>
  <li>Шаг 2</li>
</ol>

Списки можно вкладывать друг в друга: внутрь <li> ставят ещё один <ul> или <ol>.

6. Изображения (<img>)

Тег <img> вставляет изображение. Атрибуты: src (путь), alt (альтернативный текст), width и height (размеры).

<img src="cat.jpg" alt="Кот" width="300" height="200">

7. Ссылки (<a>)

Тег <a> создаёт гиперссылку. href — адрес, title — подсказка при наведении.

<a href="https://example.com" title="Перейти на сайт">Нажми меня</a>

8. Контейнер (<div>)

Тег <div> — универсальный блочный контейнер. Используется для группировки элементов.

<div>
  <p>Текст внутри div</p>
  <p>Ещё текст</p>
</div>

9. Таблицы (<table>)

Таблица состоит из строк (<tr>), ячеек-заголовков (<th>) и ячеек-данных (<td>). <thead> — шапка таблицы, <tbody> — тело.

<table>
  <thead>
    <tr>
      <th>Имя</th>
      <th>Возраст</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Анна</td>
      <td>25</td>
    </tr>
  </tbody>
</table>

10. Формы (<form>)

Тег <form> создаёт форму. Внутри — поля ввода <input> и кнопка <button>.

<form>
  <input type="text" placeholder="Введите имя">
  <button>Отправить</button>
</form>

Атрибуты input: type (текст, число, email…), placeholder (подсказка внутри поля).

11. Комментарии (<!-- -->)

Комментарии не отображаются на странице. Используются для заметок в коде.

<!-- Это комментарий -->
<p>Видимый текст</p>
