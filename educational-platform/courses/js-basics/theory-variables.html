📚 Переменные и типы данных в JavaScript

1. Что такое переменные?

Переменные в JavaScript - это контейнеры для хранения данных. Они позволяют сохранять информацию и использовать её позже в программе.

💡 Важно: JavaScript - это динамически типизированный язык, что означает, что тип переменной определяется автоматически при присвоении значения.

2. Объявление переменных

2.1. Ключевое слово let

let используется для объявления переменных, значения которых могут изменяться. 

let age = 25;
age = 26;  // Можно изменить значение
console.log(age);  // Выведет: 26

2.2. Ключевое слово const

const используется для объявления констант - переменных, значения которых нельзя изменять после присвоения. 

const PI = 3.14159;
// PI = 3.14;  // Ошибка! Нельзя изменить константу
console.log(PI);  // Выведет: 3.14159
🎯 Совет: Используйте const по умолчанию, и let только когда знаете, что значение будет меняться. Это делает код более предсказуемым.

3. Типы данных в JavaScript

3.1. Примитивные типы

Примитивные типы - это простые значения, которые не являются объектами и не имеют методов.

Тип Описание Примеры
string Текстовые данные "Hello" , 'World' , `Template ${var}`
number Числа (целые и с плавающей точкой) 42 , 3.14 , -10 , Infinity , NaN
boolean Логические значения true , false
undefined Значение не присвоено let x; (по умолчанию)
null Отсутствие значения let y = null;
symbol Уникальные идентификаторы Symbol('id')
bigint Большие целые числа 123456789012345678901234567890n

3.2. Оператор typeof

Оператор typeof возвращает строку, указывающую тип операнда. 

console.log(typeof "Hello");      // "string"
console.log(typeof 42);           // "number"
console.log(typeof true);         // "boolean"
console.log(typeof undefined);    // "undefined"
console.log(typeof null);         // "object" (особенность JS)
console.log(typeof {name: "John"}); // "object"

4. Работа со строками

4.1. Объявление строк

Строки можно создавать с помощью одинарных, двойных кавычек или обратных апострофов (шаблонные строки). 

let single = 'Одинарные кавычки';
let double = "Двойные кавычки";
let template = `Шаблонные строки`;

4.2. Шаблонные строки (Template Literals)

Шаблонные строки позволяют встраивать выражения и использовать многострочный текст. 

const name = "JavaScript";
const age = 25;

const message = `Меня зовут ${name} и мне ${age} лет.`;
console.log(message);
// Выведет: "Меня зовут JavaScript и мне 25 лет."

const multiline = `
  Это
  многострочная
  строка
`;

5. Преобразование типов

5.1. В строку

const num = 42;
const str1 = String(num);    // "42"
const str2 = num.toString(); // "42"
const str3 = num + "";       // "42"

5.2. В число

const str = "123";
const num1 = Number(str);      // 123
const num2 = parseInt(str);    // 123
const num3 = parseFloat(str); // 123
const num4 = +str;            // 123
⚠️ Внимание: Функции parseInt() и parseFloat() пытаются преобразовать строку до первого нечислового символа.

6. Практические примеры

6.1. Объявление и использование переменных

// Объявляем переменные разных типов
let userName = "Алиса";
const userAge = 28;
let isStudent = true;
let averageScore = 4.75;

// Используем переменные
console.log(`Имя: ${userName}`);
console.log(`Возраст: ${userAge}`);
console.log(`Студент: ${isStudent ? "Да" : "Нет"}`);
console.log(`Средний балл: ${averageScore}`);

// Изменяем значение переменной
userName = "Боб";
isStudent = false;

6.2. Работа с пользовательским вводом

// Получаем данные от пользователя
let firstName = prompt("Введите ваше имя:");
let birthYear = prompt("Введите год рождения:");

// Преобразуем и вычисляем возраст
let currentYear = new Date().getFullYear();
let age = currentYear - Number(birthYear);

// Выводим результат
alert(`Привет, ${firstName}! Тебе ${age} лет.`);

7. Частые ошибки и как их избежать

  • Забыли объявить переменную: Всегда используйте let или const .
  • Использование необъявленных переменных:
  • Путаница с типами: Используйте typeof для проверки типов.
  • Изменение констант: const нельзя изменять после объявления.
  • Неявное преобразование типов: Будьте внимательны с операциями, которые автоматически преобразуют типы.
