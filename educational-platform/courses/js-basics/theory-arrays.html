📦 Массивы в JavaScript

1. Что такое массив?

Массив — это упорядоченная коллекция элементов. Каждый элемент имеет свой индекс (порядковый номер). В JavaScript массивы могут содержать элементы любых типов: числа, строки, булевы значения и даже другие массивы.

💡 Важно: Индексация в массивах начинается с 0. Первый элемент имеет индекс 0, второй — 1 и так далее. 
const fruits = ["яблоко", "банан", "апельсин"];
// Индекс:       0         1         2

console.log(fruits[0]); // "яблоко"
console.log(fruits[1]); // "банан"
console.log(fruits[2]); // "апельсин"

2. Создание массива

2.1. Литерал массива (основной способ)

const numbers = [1, 2, 3, 4, 5];
const mixed = [1, "два", true, null];
const empty = [];

2.2. Конструктор Array (реже)

const arr = new Array(1, 2, 3);
console.log(arr); // [1, 2, 3]
🎯 Совет: Всегда используйте литерал массива []. Это короче и понятнее.

3. Доступ и изменение элементов

3.1. Чтение по индексу

Используйте квадратные скобки с индексом элемента:

const colors = ['red', 'green', 'blue'];
console.log(colors[0]); // 'red'
console.log(colors[2]); // 'blue'

3.2. Изменение по индексу

const fruits = ['apple', 'banana', 'cherry'];
fruits[1] = 'mango';
console.log(fruits); // ['apple', 'mango', 'cherry']
📝 Свойство length: arr.length возвращает количество элементов. Последний элемент всегда находится по индексу arr.length - 1.

4. Добавление и удаление элементов

4.1. push() — добавить в конец

Добавляет один или несколько элементов в конец массива. Возвращает новую длину массива.

const numbers = [1, 2, 3];
numbers.push(4, 5);
console.log(numbers);       // [1, 2, 3, 4, 5]
console.log(numbers.length); // 5

4.2. pop() — удалить с конца

Удаляет последний элемент из массива и возвращает его. Массив уменьшается на один элемент.

const items = ['a', 'b', 'c'];
const removed = items.pop();
console.log(removed); // 'c'
console.log(items);   // ['a', 'b']

4.3. unshift() — добавить в начало

Добавляет элемент в начало массива, сдвигая остальные вправо.

const data = [10, 20, 30];
data.unshift('start');
console.log(data); // ['start', 10, 20, 30]

4.4. shift() — удалить из начала

Удаляет первый элемент массива и возвращает его. Остальные сдвигаются влево.

const queue = [100, 200, 300];
queue.shift();
console.log(queue); // [200, 300]
Метод Действие Возвращает Изменяет исходный
push(el) Добавляет в конец Новую длину ✅ Да
pop() Удаляет с конца Удалённый элемент ✅ Да
unshift(el) Добавляет в начало Новую длину ✅ Да
shift() Удаляет из начала Удалённый элемент ✅ Да

5. Поиск и проверка

5.1. indexOf() — поиск индекса

Возвращает индекс первого найденного элемента или -1, если элемент не найден.

const scores = [10, 20, 30, 25, 40];
console.log(scores.indexOf(25)); // 3
console.log(scores.indexOf(99)); // -1 (не найден)

5.2. includes() — проверка наличия

Возвращает true, если элемент есть в массиве, иначе false.

const animals = ['dog', 'cat', 'bird'];
console.log(animals.includes('cat')); // true
console.log(animals.includes('fish')); // false

6. slice() — копирование части массива

slice(start, end) возвращает новый массив, содержащий элементы с индекса start до end (не включая end). Исходный массив не изменяется.

const letters = ['a', 'b', 'c', 'd', 'e'];
const part = letters.slice(1, 4);
console.log(part);   // ['b', 'c', 'd']
console.log(letters); // ['a', 'b', 'c', 'd', 'e'] (не изменился)
🎯 Совет: slice() без аргументов копирует весь массив: const copy = arr.slice().

7. splice() — удаление и вставка

splice(start, deleteCount, item1, item2, ...) изменяет массив: удаляет элементы и/или вставляет новые.

const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May'];
months.splice(2, 2, 'X', 'Y');
//       start: 2  (с какого индекса)
//   deleteCount: 2  (сколько удалить)
//   вставляем: 'X', 'Y'

console.log(months); // ['Jan', 'Feb', 'X', 'Y', 'May']

Можно использовать splice и только для удаления:

const arr = [1, 2, 3, 4, 5];
arr.splice(1, 2); // удаляем 2 элемента с индекса 1
console.log(arr); // [1, 4, 5]

8. concat() — объединение массивов

concat() объединяет два или более массивов в новый массив. Исходные не изменяются.

const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = arr1.concat(arr2);
console.log(combined); // [1, 2, 3, 4]

// Можно использовать spread-оператор:
const combined2 = [...arr1, ...arr2];
console.log(combined2); // [1, 2, 3, 4]

9. reverse() — переворот массива

reverse() переворачивает массив — первый элемент становится последним, последний — первым. Изменяет исходный массив.

const nums = [1, 2, 3, 4, 5];
nums.reverse();
console.log(nums); // [5, 4, 3, 2, 1]

10. sort() — сортировка

10.1. Сортировка строк

sort() сортирует строки в алфавитном порядке. Изменяет исходный массив.

const names = ['John', 'Anna', 'Zoe', 'Bob'];
names.sort();
console.log(names); // ['Anna', 'Bob', 'John', 'Zoe']

10.2. Сортировка чисел (с функцией сравнения)

⚠️ Важно: sort() без функции сравнения сортирует числа как строки! [10, 2, 5].sort() даст [10, 2, 5]. 
const numbers = [10, 2, 5, 1, 9];
numbers.sort((a, b) => a - b);  // по возрастанию
console.log(numbers); // [1, 2, 5, 9, 10]

numbers.sort((a, b) => b - a);  // по убыванию
console.log(numbers); // [10, 9, 5, 2, 1]
📝 Как работает функция сравнения: Если (a, b) => a - b возвращает отрицательное число, a ставится перед b. Если положительное — b перед a.

11. Удаление дубликатов через Set

Объект Set хранит только уникальные значения. Комбинируя его с spread-оператором, можно легко убрать дубликаты:

const data = [3, 8, 1, 8, 5, 3, 9, 9, 2];
const unique = [...new Set(data)];
console.log(unique); // [3, 8, 1, 5, 9, 2]

13. Практические советы

  • const для массива: можно объявлять массив через const — это не запрещает изменять его содержимое (добавлять, удалять, менять элементы).
  • Проверка на массив: используйте Array.isArray(arr) — typeof arr вернёт "object".
  • Длина массива: arr.length можно не только читать, но и изменять — это укорачивает массив.
  • Пустые элементы: const arr = [1, , 3] создаёт массив с пустым элементом. Избегайте этого.
