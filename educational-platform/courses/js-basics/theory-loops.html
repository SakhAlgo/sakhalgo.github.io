🔄 Циклы в JavaScript

1. Что такое цикл?

Цикл — это конструкция, которая позволяет выполнять один и тот же блок кода многократно. Циклы используются, когда нужно повторить действие несколько раз или перебрать элементы коллекции (массива, объекта).

💡 Важно: Без циклов нам пришлось бы писать один и тот же код снова и снова. Циклы делают код компактным и гибким.

2. Цикл for

Цикл for — самый распространённый цикл. Он состоит из трёх частей:

  • Инициализация — создаёт счётчик (выполняется один раз в начале)
  • Условие — проверяется перед каждой итерацией
  • Шаг — выполняется после каждой итерации
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
// Выведет: 1 2 3 4 5

Как это работает:

  1. let i = 1 — создаём переменную-счётчик со значением 1
  2. i <= 5 — проверяем условие. Если true — выполняем тело цикла
  3. console.log(i) — тело цикла (выводим i)
  4. i++ — увеличиваем i на 1
  5. Возвращаемся к шагу 2
🎯 Важно: Переменная i — это традиционное имя для счётчика цикла. Можно использовать любое имя.

2.1. Обратный отсчёт

for (let i = 5; i >= 1; i--) {
    console.log(i);
}
// Выведет: 5 4 3 2 1

2.2. Шаг больше 1

for (let i = 0; i <= 10; i += 2) {
    console.log(i);
}
// Выведет: 0 2 4 6 8 10

3. Цикл while

Цикл while выполняется, пока условие истинно. Он проверяет условие перед каждой итерацией.

let i = 1;
while (i <= 5) {
    console.log(i);
    i++;
}
// Выведет: 1 2 3 4 5
⚠️ Осторожно: Если условие всегда истинно, цикл станет бесконечным! Убедитесь, что счётчик меняется внутри цикла.

4. Цикл do...while

Цикл do...while похож на while, но он проверяет условие после выполнения тела. Значит, тело выполнится хотя бы один раз.

let i = 1;
do {
    console.log(i);
    i++;
} while (i <= 5);
// Выведет: 1 2 3 4 5

// Даже если условие false с самого начала:
let j = 10;
do {
    console.log(j);
    j++;
} while (j <= 5);
// Выведет: 10 (выполнится один раз)

5. Перебор массивов

5.1. Цикл for для массива

Массивы перебираются по индексам от 0 до длины массива минус 1.

const fruits = ["яблоко", "банан", "апельсин"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
// Выведет: яблоко банан апельсин

5.2. Цикл for...of

Современный способ перебора элементов массива. Более короткий и читаемый.

const fruits = ["яблоко", "банан", "апельсин"];

for (const fruit of fruits) {
    console.log(fruit);
}
// Выведет: яблоко банан апельсин
🎯 Совет: for...of удобнее, когда нам не нужен индекс элемента. Он автоматически перебирает все элементы массива.

6. Перебор объектов (for...in)

Цикл for...in используется для перебора свойств объекта.

const user = {
    name: "Алиса",
    age: 25,
    city: "Москва"
};

for (const key in user) {
    console.log(key + ": " + user[key]);
}
// Выведет:
// name: Алиса
// age: 25
// city: Москва
⚠️ Важно: for...in предназначен для объектов, а не для массивов. Для массивов используйте for...of.

7. Управление циклом: break и continue

7.1. break — прерывание цикла

break немедленно завершает выполнение цикла.

for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break;  // Цикл остановится на 5
    }
    console.log(i);
}
// Выведет: 1 2 3 4

Часто break используют для поиска: как только нашли нужный элемент — прекращаем поиск.

7.2. continue — пропуск итерации

continue пропускает текущую итерацию и переходит к следующей.

for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        continue;  // Пропускаем чётные числа
    }
    console.log(i);
}
// Выведет: 1 3 5 7 9

8. Вложенные циклы

Цикл может содержать другой цикл внутри себя. Это называется вложенными циклами.

for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 3; j++) {
        console.log(i + " × " + j + " = " + (i * j));
    }
    console.log("---");
}

Внешний цикл выполняется 3 раза, и каждый раз внутренний цикл выполняется полностью (3 раза). Итого — 9 итераций.

📝 Пример: Вложенные циклы часто используют для создания таблиц, матриц и всех комбинаций элементов.

9. Сравнение циклов

Цикл Когда использовать Пример
for Когда известно количество повторений for (let i = 0; i < 5; i++)
while Когда повторяем, пока условие истинно while (num > 0)
do...while Когда нужно выполнить хотя бы один раз do { ... } while (cond)
for...of Для перебора элементов массива for (const item of arr)
for...in Для перебора свойств объекта for (const key in obj)

10. Практические примеры

10.1. Сумма чисел от 1 до N

function sumTo(n) {
    let sum = 0;
    for (let i = 1; i <= n; i++) {
        sum += i;
    }
    return sum;
}

console.log(sumTo(5));  // Выведет: 15 (1+2+3+4+5)
console.log(sumTo(10)); // Выведет: 55

10.2. Таблица умножения

function multiplicationTable() {
    for (let i = 1; i <= 10; i++) {
        let row = "";
        for (let j = 1; j <= 10; j++) {
            row += (i * j) + "\t";
        }
        console.log(row);
    }
}

10.3. Поиск в массиве

function findNumber(arr, target) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] === target) {
            return i;  // Нашли — возвращаем индекс
        }
    }
    return -1;  // Не нашли
}

const numbers = [10, 20, 30, 40, 50];
console.log(findNumber(numbers, 30));  // Выведет: 2
console.log(findNumber(numbers, 99));  // Выведет: -1

11. Частые ошибки

  • Бесконечный цикл: если условие никогда не станет false, цикл будет выполняться вечно. Проверяйте, что счётчик меняется.
  • Ошибка на единицу (off-by-one): например, i <= arr.length вместо i < arr.length — выход за границы массива.
  • Забыли инициализировать счётчик: переменная может содержать неожиданное значение.
  • Изменение массива во время перебора: может привести к пропуску элементов.
