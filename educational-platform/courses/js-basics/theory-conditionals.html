🔀 Ветвления в JavaScript

1. Что такое ветвления?

Ветвления позволяют выполнять разные блоки кода в зависимости от условий. Это основа принятия решений в программировании.

💡 Важно: Условия всегда возвращают true (истина) или false (ложь).

2. if (простое условие)

Конструкция if выполняет блок кода, если условие истинно.

let age = 18;

if (age >= 18) {
    console.log("Вы совершеннолетний");
}

Операторы сравнения

ОператорОписаниеПример
===Строгое равенство5 === "5" // false
!==Строгое неравенство5 !== "5" // true
>Больше10 > 5 // true
<Меньше10 < 5 // false
>=Больше или равно5 >= 5 // true
<=Меньше или равно4 <= 5 // true

3. if...else (условие с альтернативой)

Конструкция if...else выполняет один блок кода, если условие истинно, и другой блок, если ложно.

let age = 16;

if (age >= 18) {
    console.log("Доступ разрешён");
} else {
    console.log("Доступ запрещён");
}

// Выведет: "Доступ запрещён"

4. if...else if...else (несколько условий)

Позволяет проверить несколько условий последовательно.

let score = 85;

if (score >= 90) {
    console.log("Оценка: Отлично");
} else if (score >= 75) {
    console.log("Оценка: Хорошо");
} else if (score >= 50) {
    console.log("Оценка: Удовлетворительно");
} else {
    console.log("Оценка: Неудовлетворительно");
}

// Выведет: "Оценка: Хорошо"

5. Вложенные if

Один if может находиться внутри другого.

let age = 20;
let hasLicense = true;

if (age >= 18) {
    console.log("Вы совершеннолетний");
    if (hasLicense) {
        console.log("И у вас есть права!");
    } else {
        console.log("Но у вас нет прав");
    }
}

6. Логические операторы

&& (И) — оба условия истинны

if (age >= 18 && hasTicket) {
    console.log("Можете войти");
}

|| (ИЛИ) — хотя бы одно истинно

if (isAdmin || isModerator) {
    console.log("Доступ есть");
}

! (НЕ) — инвертирует условие

if (!isLoggedIn) {
    console.log("Войдите в систему");
}

7. prompt() и confirm()

prompt() — запрос ввода

prompt() показывает диалоговое окно с полем для ввода и возвращает строку.

let name = prompt("Как вас зовут?");
if (name) {
    console.log("Привет, " + name + "!");
}

confirm() — запрос подтверждения

confirm() возвращает true (OK) или false (Отмена).

let likesJs = confirm("Вам нравится JavaScript?");
if (likesJs) {
    alert("JS - это круто!");
} else {
    alert("Попробуйте ещё!");
}
🎯 Совет: prompt() всегда возвращает строку. Для числа используйте Number(prompt(...)).
