📚 Функции в JavaScript

1. Что такое функция?

Функция — это блок кода, который можно определить один раз и выполнять (вызывать) многократно. Функции помогают избегать повторения кода и делают программу более структурированной.

💡 Важно: Функции — это один из основных строительных блоков JavaScript. Они позволяют организовать код в логические блоки и переиспользовать его.

2. Объявление функции

2.1. Function Declaration (объявление функции)

Классический способ объявления функции с помощью ключевого слова function.

function greet() {
    console.log("Привет, мир!");
}

// Вызов функции
greet();  // Выведет: "Привет, мир!"
🎯 Особенность: Function Declaration можно вызывать до их объявления в коде. Это называется "hoisting" (поднятие).

2.2. Function Expression (функциональное выражение)

Функцию можно сохранить в переменную. Такая функция создаётся в момент выполнения кода.

const greet = function() {
    console.log("Привет, мир!");
};

greet();  // Выведет: "Привет, мир!"

// Нельзя вызвать до объявления!
// greet(); // Ошибка, если вызвать раньше

3. Параметры и аргументы

Функции могут принимать параметры — переменные, которые получают значения при вызове функции. Эти значения называются аргументами.

// Функция с одним параметром
function greet(name) {
    console.log("Привет, " + name + "!");
}

greet("Алиса");  // Выведет: "Привет, Алиса!"
greet("Боб");    // Выведет: "Привет, Боб!"

// Функция с двумя параметрами
function sum(a, b) {
    console.log(a + b);
}

sum(3, 5);  // Выведет: 8
sum(10, 20); // Выведет: 30
⚠️ Важно: Если не передать аргумент для параметра, его значение будет undefined.

4. Возврат значения (return)

Функция может возвращать результат своей работы с помощью ключевого слова return.

function sum(a, b) {
    return a + b;
}

const result = sum(3, 5);
console.log(result);  // Выведет: 8

console.log(sum(10, 20));  // Выведет: 30
💡 Важно: После выполнения return функция немедленно завершает свою работу. Код после return не выполняется. Если return не указан, функция возвращает undefined. 
function checkAge(age) {
    if (age >= 18) {
        return "Доступ разрешён";
    }
    return "Доступ запрещён";
    // console.log("Этот код никогда не выполнится");
}

console.log(checkAge(20));  // Выведет: "Доступ разрешён"
console.log(checkAge(15));  // Выведет: "Доступ запрещён"

5. Стрелочные функции (Arrow Functions)

Стрелочные функции — это более короткая форма записи функций, добавленная в современном JavaScript (ES6).

// Обычная функция
function add(a, b) {
    return a + b;
}

// Стрелочная функция
const add = (a, b) => {
    return a + b;
};

// Если тело функции состоит из одного выражения,
// можно сократить ещё больше:
const add = (a, b) => a + b;

const result = add(3, 5);
console.log(result);  // Выведет: 8

5.1. Стрелочная функция с одним параметром

Если у стрелочной функции только один параметр, круглые скобки можно опустить.

// Обычная функция
function double(x) {
    return x * 2;
}

// Стрелочная функция с одним параметром (можно без скобок)
const double = x => x * 2;

console.log(double(5));  // Выведет: 10
🎯 Совет: Стрелочные функции особенно удобны для коротких однострочных операций. Для сложных функций лучше использовать обычный синтаксис для лучшей читаемости.

6. Вложенные вызовы функций

Функции можно вызывать внутри других функций, передавая результат одной функции как аргумент другой.

function double(x) {
    return x * 2;
}

function addFive(x) {
    return x + 5;
}

// Вложенный вызов: сначала double, потом addFive
const result = addFive(double(10));
console.log(result);  // Выведет: 25 (10 * 2 + 5)

// Можно записать поэтапно:
const doubled = double(10);  // 20
const final = addFive(doubled); // 25
console.log(final);  // Выведет: 25
// Функция форматирования
function formatName(name) {
    return name.trim().toUpperCase();
}

// Функция приветствия
function greetUser(name) {
    const formatted = formatName(name);
    return "Привет, " + formatted + "!";
}

console.log(greetUser("  алиса  "));  // Выведет: "Привет, АЛИСА!"

7. Сравнение: разные способы создания функций

Способ Синтаксис Hoisting Когда использовать
Function Declaration function f() {} Да Для основных функций в коде
Function Expression const f = function() {} Нет Для колбэков и условного создания
Arrow Function const f = () => {} Нет Для коротких функций, особенно в колбэках

8. Практические примеры

8.1. Функция для расчёта скидки

function calculateDiscount(price, discountPercent) {
    const discount = price * discountPercent / 100;
    return price - discount;
}

const finalPrice = calculateDiscount(1000, 20);
console.log(finalPrice);  // Выведет: 800

8.2. Функция для проверки чётности

function isEven(number) {
    return number % 2 === 0;
}

console.log(isEven(4));  // Выведет: true
console.log(isEven(7));  // Выведет: false

8.3. Комбинация функций

function celsiusToFahrenheit(celsius) {
    return celsius * 9/5 + 32;
}

function fahrenheitToCelsius(fahrenheit) {
    return (fahrenheit - 32) * 5/9;
}

console.log(celsiusToFahrenheit(0));   // Выведет: 32
console.log(celsiusToFahrenheit(100)); // Выведет: 212
console.log(fahrenheitToCelsius(32));  // Выведет: 0

9. Частые ошибки

  • Забыли вызвать функцию: console.log(greet) выведет саму функцию, а не результат. Нужно: console.log(greet())
  • Забыли return: Если не указать return, функция вернёт undefined
  • Путаница между параметрами и аргументами: Параметры — в объявлении, аргументы — при вызове
  • Изменение параметров внутри функции: Примитивные типы передаются по значению
  • Слишком сложные функции: Лучше разбивать на маленькие функции
