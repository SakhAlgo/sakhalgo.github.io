Функции в Python

Определение функции

Функция в Python определяется с помощью ключевого слова def:

def greet():
    print("Привет, мир!")

Вызов функции

greet()  # Выведет: Привет, мир!

Функция с параметрами

def greet_person(name):
    print(f"Привет, {name}!")

greet_person("Alice")  # Привет, Alice!

Возврат значения

def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

Параметры по умолчанию

def repeat(text, times=1):
    return text * times

print(repeat("Hi"))       # Hi
print(repeat("Hi", 3))   # HiHiHi

Лямбда-функции

Лямбда — это анонимная функция, которая определяется в одну строку:

square = lambda x: x ** 2
print(square(5))  # 25

# Использование с sorted:
pairs = [(1, 'b'), (2, 'a')]
pairs.sort(key=lambda x: x[1])
print(pairs)  # [(2, 'a'), (1, 'b')]
Важно: Тело функции определяется отступом (4 пробела). Все строки с одинаковым отступом после def считаются телом функции.

Условные операторы в Python

Оператор if

age = 18
if age >= 18:
    print("Вы совершеннолетний")

if/else

age = 16
if age >= 18:
    print("Доступ разрешен")
else:
    print("Доступ запрещен")

if/elif/else

score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
print(f"Оценка: {grade}")

Логические операторы

# and — И (оба условия истинны)
if age >= 18 and has_ticket:
    print("Проходите")

# or — ИЛИ (хотя бы одно истинно)
if is_admin or is_owner:
    print("Доступ разрешен")

# not — НЕ (отрицание)
if not is_banned:
    print("Вы не забанены")

Тернарный оператор

Краткая форма if/else в одну строку:

status = "взрослый" if age >= 18 else "ребенок"
Важно: В Python отступы определяют блок кода. Все строки внутри if/elif/else должны иметь одинаковый отступ (4 пробела).

Циклы в Python

Цикл for

Цикл for используется для перебора элементов последовательности:

# Перебор строки
for char in "Python":
    print(char)

# Перебор списка
for fruit in ["apple", "banana", "cherry"]:
    print(fruit)

Функция range()

# range(5) → 0, 1, 2, 3, 4
for i in range(5):
    print(i)

# range(2, 7) → 2, 3, 4, 5, 6
for i in range(2, 7):
    print(i)

# range(0, 10, 2) → 0, 2, 4, 6, 8 (шаг 2)
for i in range(0, 10, 2):
    print(i)

Цикл while

Цикл while выполняется, пока условие истинно:

count = 0
while count < 5:
    print(count)
    count += 1

Break и Continue

# break — досрочный выход из цикла
for i in range(10):
    if i == 5:
        break  # цикл прервется на 5
    print(i)

# continue — пропуск итерации
for i in range(5):
    if i == 2:
        continue  # пропустит 2
    print(i)

Вложенные циклы

for i in range(3):
    for j in range(2):
        print(f"({i}, {j})")
Важно: В Python нет цикла do-while. Для бесконечного цикла используйте while True:

Списки в Python

Создание списка

fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]
empty = []

Индексация

fruits = ["apple", "banana", "cherry"]
print(fruits[0])   # apple
print(fruits[1])   # banana
print(fruits[-1])  # cherry (последний элемент)
print(fruits[-2])  # banana (предпоследний)

Методы списков

nums = [1, 2, 3]

# Добавление
nums.append(4)        # [1, 2, 3, 4]
nums.insert(0, 0)    # [0, 1, 2, 3, 4]

# Удаление
nums.remove(2)        # [0, 1, 3, 4]
last = nums.pop()      # last = 4, nums = [0, 1, 3]

# Информация
idx = nums.index(3)    # 2
count = nums.count(1)  # 1
length = len(nums)     # 3

Срезы списков

nums = [0, 1, 2, 3, 4, 5]

print(nums[1:4])   # [1, 2, 3]
print(nums[:3])    # [0, 1, 2]
print(nums[3:])    # [3, 4, 5]
print(nums[::2])   # [0, 2, 4]
print(nums[::-1])  # [5, 4, 3, 2, 1, 0]

Генератор списка (List Comprehension)

# Квадраты чисел от 0 до 9
squares = [x**2 for x in range(10)]

# Чётные числа
evens = [x for x in range(20) if x % 2 == 0]

# Матрица 3x3
matrix = [[i * 3 + j for j in range(3)] for i in range(3)]
Важно: Списки — изменяемый тип данных. Элементы списка можно менять после создания: nums[0] = 10

Словари в Python

Создание словаря

Словарь хранит пары "ключ — значение":

person = {
    "name": "Alice",
    "age": 25,
    "city": "Moscow"
}

empty = {}
scores = dict(a=10, b=20)

Доступ к элементам

print(person["name"])   # Alice

# get() с значением по умолчанию
print(person.get("age"))           # 25
print(person.get("country", "Россия"))  # Россия

Изменение словаря

# Добавление/изменение
person["email"] = "alice@example.com"
person["age"] = 26

# Удаление
del person["city"]
person.pop("email")

Методы словарей

print(person.keys())    # dict_keys(['name', 'age'])
print(person.values())  # dict_values(['Alice', 26])
print(person.items())   # dict_items([('name', 'Alice'), ('age', 26)])

Перебор словаря

# Перебор ключей
for key in person:
    print(key)

# Перебор значений
for value in person.values():
    print(value)

# Перебор пар ключ-значение
for key, value in person.items():
    print(f"{key}: {value}")

Проверка наличия ключа

if "name" in person:
    print("Ключ 'name' существует")

Вложенные словари

users = {
    "alice": {"age": 25, "role": "admin"},
    "bob": {"age": 30, "role": "user"}
}
print(users["alice"]["role"])  # admin
Важно: Ключи словаря должны быть неизменяемыми (строки, числа, кортежи). Значениями могут быть любые типы данных.

Строки в Python

Создание строк

s1 = 'Hello'
s2 = "World"
s3 = '''Multi-line
string'''

Методы строк

text = "  Hello, Python!  "

print(text.upper())          # "  HELLO, PYTHON!  "
print(text.lower())          # "  hello, python!  "
print(text.strip())          # "Hello, Python!"
print(text.replace("Python", "World"))  # "  Hello, World!  "
print(text.startswith("Hello"))  # False (из-за пробелов)
print(text.endswith("!"))     # False

Форматирование строк

# F-строки (Python 3.6+)
name, age = "Alice", 25
print(f"Name: {name}, Age: {age}")
print(f"{name:>10}")  # выравнивание вправо

# format()
print("Name: {}, Age: {}".format(name, age))

# %-format (старый стиль)
print("Name: %s, Age: %d" % (name, age))

Разделение и соединение

# split — разделяет строку на список
sentence = "apple,banana,cherry"
fruits = sentence.split(",")
print(fruits)  # ['apple', 'banana', 'cherry']

# join — соединяет список в строку
new_sentence = " - ".join(fruits)
print(new_sentence)  # "apple - banana - cherry"

Поиск подстроки

text = "Hello, Python!"

# find — ищет подстроку, возвращает индекс или -1
print(text.find("Python"))  # 7
print(text.find("Java"))   # -1

# in — проверяет наличие подстроки
print("Python" in text)  # True

Проверка строк

print("123".isdigit())      # True
print("abc".isalpha())      # True
print("abc123".isalnum())   # True
print("  ".isspace())       # True
print("Hello".istitle())    # True
Важно: Строки в Python — неизменяемый тип. Методы строк не изменяют исходную строку, а возвращают новую.
