Строки в Python

Строки (str) — это неизменяемые последовательности символов. Поддерживают множество встроенных методов.

Создание строк

s1 = "Python"
s2 = 'Python'
s3 = """Многострочный
текст"""
s4 = "Строка с 'кавычками'"

Методы строк

text = "Hello World"

text.upper()            # "HELLO WORLD"
text.lower()            # "hello world"
text.capitalize()       # "Hello world"
text.title()            # "Hello World"

text.strip()            # удалить пробелы по краям
text.lstrip()           # удалить слева
text.rstrip()           # удалить справа

text.replace("World", "Python")  # "Hello Python"

len(text)               # 11 — длина строки

Поиск и проверка

text = "Python programming"

# Поиск подстроки
"Python" in text           # True
text.find("prog")          # 7 — индекс первого вхождения
text.find("Java")          # -1 — не найдено
text.index("prog")         # 7 — как find, но вызывает ошибку

# Проверка содержимого
"123".isdigit()            # True
"abc".isalpha()            # True
"abc123".isalnum()         # True (буквы + цифры)
"   ".isspace()            # True
"Hello".startswith("He")   # True
"World".endswith("ld")     # True

Разделение и соединение

text = "яблоко,банан,апельсин"

# Разделение на список
fruits = text.split(",")
print(fruits)  # ['яблоко', 'банан', 'апельсин']

# Разделение по пробелам
words = "a b c".split()
print(words)   # ['a', 'b', 'c']

# Соединение списка в строку
joined = " - ".join(fruits)
print(joined)  # 'яблоко - банан - апельсин'

Форматирование строк

name = "Анна"
age = 25

# F-строки (Python 3.6+)
print(f"Меня зовут {name}, мне {age} лет")

# Метод format()
print("Меня зовут {}, мне {} лет".format(name, age))

# По индексам
print("{1} — {0}".format("Python", "код"))

# По именам
print("{name}, возраст: {age}".format(name="Иван", age=30))

Индексация и срезы строк

text = "Python"
print(text[0])     # P
print(text[-1])    # n
print(text[1:4])   # yth
print(text[:3])    # Pyt
print(text[::-1])  # nohtyP — переворот строки

Важно: строки неизменяемы

s = "hello"
# s[0] = "H"  # TypeError!
s = "H" + s[1:]  # Правильно: "Hello"
