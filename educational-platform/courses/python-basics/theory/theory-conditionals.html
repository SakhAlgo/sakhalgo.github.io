Условные операторы в Python

Условные операторы позволяют выполнять код в зависимости от условий.

Оператор if

Базовый условный оператор:

x = 10
if x > 5:
    print("x больше 5")

Оператор if/else

Выполняет один блок кода при истинности условия, другой — при ложности:

x = 3
if x > 5:
    print("Больше 5")
else:
    print("Меньше или равно 5")

Оператор if/elif/else

Для множественных условий используйте elif (сокращение от else if):

x = 0
if x > 0:
    print("Положительное")
elif x < 0:
    print("Отрицательное")
else:
    print("Ноль")

Логические оператор

  • and — логическое И (оба условия истинны)
  • or — логическое ИЛИ (хотя бы одно истинно)
  • not — логическое НЕ (отрицание)
age = 25
has_license = True

if age >= 18 and has_license:
    print("Можно водить машину")

is_weekend = False
if not is_weekend:
    print("Сегодня будний день")

Тернарный оператор

Краткая форма записи if/else в одну строку:

x = 7
result = "Большой" if x > 5 else "Маленький"
print(result)
