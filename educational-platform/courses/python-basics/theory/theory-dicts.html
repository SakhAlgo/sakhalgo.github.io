Словари в Python

Словарь (dict) — это неупорядоченная коллекция пар "ключ-значение". Ключи должны быть уникальными и неизменяемыми.

Создание словаря

# Пустой словарь
empty = {}

# Словарь с элементами
person = {"name": "Анна", "age": 25, "city": "Москва"}

# Через конструктор dict()
person2 = dict(name="Иван", age=30)

Доступ к элементам

person = {"name": "Анна", "age": 25}

# Через квадратные скобки
print(person["name"])  # Анна

# Через get() — безопасный доступ
print(person.get("age"))     # 25
print(person.get("city", "Не указан"))  # Не указан

# person["city"] — вызовет ошибку KeyError!

Изменение и добавление

person = {"name": "Анна"}

# Добавление нового ключа
person["age"] = 25

# Изменение существующего
person["name"] = "Мария"

# Обновление нескольких ключей
person.update({"city": "Москва", "age": 26})

Основные методы словарей

person = {"name": "Анна", "age": 25}

person.keys()      # dict_keys(['name', 'age'])
person.values()    # dict_values(['Анна', 25])
person.items()     # dict_items([('name', 'Анна'), ('age', 25)])

# Проверка наличия ключа
print("name" in person)     # True
print("city" not in person) # True

# Удаление
del person["age"]           # удалить ключ
person.pop("name")          # удалить и вернуть значение
person.clear()              # очистить словарь

Перебор словаря

person = {"name": "Анна", "age": 25, "city": "Москва"}

# По ключам
for key in person:
    print(f"{key}: {person[key]}")

# По значениям
for value in person.values():
    print(value)

# По парам ключ-значение
for key, value in person.items():
    print(f"{key} = {value}")

Вложенные словари

users = {
    "user1": {"name": "Анна", "age": 25},
    "user2": {"name": "Иван", "age": 30}
}

print(users["user1"]["name"])  # Анна

# Добавление вложенного словаря
users["user3"] = {"name": "Ольга", "age": 28}

Что может быть ключом?

Ключами могут быть только неизменяемые типы: str, int, float, tuple. Списки и словари ключами быть не могут.

# Можно
d = {1: "один", "key": "value", (1, 2): "tuple"}

# Нельзя — list не может быть ключом
# d = {[1, 2]: "error"}  # TypeError!
