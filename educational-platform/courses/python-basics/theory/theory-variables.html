Переменные и типы данных в Python

Переменные

В Python переменная — это имя, которое ссылается на значение. Python — язык с динамической типизацией: тип переменной определяется автоматически по присвоенному значению.

name = "Python"
age = 30
is_fun = True
pi = 3.14
Правила именования переменных:
  • Могут содержать буквы, цифры и знак подчеркивания
  • Не могут начинаться с цифры
  • Регистр имеет значение: name и Name — разные переменные
  • Рекомендуется стиль snake_case

Основные типы данных

str (строка)

Строки создаются с помощью одинарных или двойных кавычек:

text1 = 'Привет'
text2 = "Мир"
multiline = '''Многострочная
строка'''

int (целое число)

count = 42
negative = -10
big = 1_000_000  # можно использовать подчеркивания

float (число с плавающей точкой)

price = 99.99
scientific = 1.5e-2  # 0.015

bool (булево значение)

is_active = True
is_empty = False

Проверка типа

Функция type() возвращает тип переменной:

x = 5
print(type(x))  # 

y = "Hello"
print(type(y))  #

Приведение типов

num_str = "123"
num_int = int(num_str)     # строка → целое число
num_float = float(num_str) # строка → число с плавающей точкой
text = str(456)          # число → строка

F-строки

F-строки позволяют вставлять значения переменных внутрь строки:

name = "Alice"
age = 25
print(f"Меня зовут {name}, мне {age} лет")
Важно: F-строки доступны начиная с Python 3.6. Они обозначаются префиксом f перед строкой.
