Циклы в Python

Циклы позволяют выполнять один и тот же блок кода многократно.

Цикл for

Цикл for используется для перебора последовательностей (списков, строк, диапазонов):

# Перебор чисел от 0 до 4
for i in range(5):
    print(i)

# Перебор чисел от 1 до 5
for i in range(1, 6):
    print(i)

# Перебор с шагом
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8

Цикл while

Цикл while выполняется, пока условие истинно:

count = 0
while count < 5:
    print(count)
    count += 1

Оператор break

Прерывает выполнение цикла досрочно:

for i in range(10):
    if i == 5:
        break
    print(i)  # Выведет: 0, 1, 2, 3, 4

Оператор continue

Пропускает текущую итерацию и переходит к следующей:

for i in range(5):
    if i == 2:
        continue
    print(i)  # Выведет: 0, 1, 3, 4

Вложенные циклы

Циклы можно вкладывать друг в друга:

for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} * {j} = {i * j}")
    print("---")
