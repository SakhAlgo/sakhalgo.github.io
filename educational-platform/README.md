# 📚 AlgoCode — Образовательная платформа

Интерактивная платформа для обучения веб-разработке с встроенным редактором кода, эталонными решениями и автоматической проверкой заданий.

Проект работает полностью на клиентской стороне, без бэкенда.

---

## 🚀 Запуск проекта

Для работы требуется HTTP-сервер (из-за ES-модулей и fetch):

```bash
# Node.js (рекомендуется)
npx serve .

# Python 3
python -m http.server 8080

# VS Code
# Установите расширение "Live Server" → ПКМ на index.html → Open with Live Server
```

Затем откройте в браузере: `http://localhost:8080`

## ➕ Добавление нового задания

### 1. Создайте структуру в соответствующем курсе:
```
courses/[название-курса]/tasks/[номер-задания]/
├── task.json
├── sample.html
├── sample.css
└── sample.js
```

### 2. Создайте валидатор задания:
```
courses/[название-курса]/validators/task-[номер].js
```

### 3. Зарегистрируйте задание в `js/tasks/task-manifest.js`:
```javascript
{
  id:         '046',
  course:     'html-css-basics',
  title:      'Модальное окно',
  difficulty: 'medium',
  stars:      '⭐⭐',
  points:     200,
  tags:       ['html', 'css'],
  validator:  'courses/html-css-basics/validators/task-046.js',
  taskPath:   'courses/html-css-basics/tasks/046-modal-window/'
}
```

### 4. Запустите тесты для проверки корректности:
```bash
npm test
```

## 🏗 Архитектурные особенности

✅ **Безопасный рендер**: Код пользователя выполняется в изолированном `<iframe sandbox>` через Blob URL, без доступа к основной странице.

✅ **Ленивая загрузка**: Валидаторы заданий динамически импортируются только при открытии задания.

✅ **Версионированное хранилище**: Автосохранение кода пользователя с резервными копиями.

✅ **Базовый класс валидатора**: Предоставляет готовые утилиты для проверки DOM, CSS и JavaScript.

---

## 📊 Система оценивания

Каждая проверка имеет собственный вес. Итоговый балл рассчитывается по формуле:
```
score = (сумма весов пройденных проверок / общая сумма весов) × 100
```

Задание считается пройденным при достижении порога (по умолчанию 70%).
