# План реализации мобильного приложения «Пумсе-Тренер» для Android

## 1. Анализ продукта и целевая аудитория

| Сегмент | Потребности | Особенности реализации |
|---------|-------------|------------------------|
| **Дети 6–14 лет** | Визуальное обучение, геймификация, мгновенная обратная связь | Яркий UI, анимации, система достижений, голосовые подсказки |
| **Родители** | Контроль прогресса, безопасность, отчётность | Родительский кабинет, уведомления о достижениях, экспорт статистики |
| **Тренеры/школы** | Стандартизация обучения, удалённая проверка | B2B-модуль для школ, групповые задания, аналитика группы |

> **Стандарты пумсе**: Приложение охватывает WTF/WT пумсе (Тэгук 1–8, Чаги 1–9). При необходимости — поддержка ITF тули.

## 2. Функциональная архитектура по версиям

### 🚀 MVP (v1.0) — 3–4 месяца

- 📱 Видео- и 3D-анимационные демонстрации всех пумсе с разбивкой по движениям
- 📋 Интерактивная «карта прогресса» с разблокировкой форм по поясам
- 🎯 Тренировочный режим «повтори за тренером» (без ИИ)
- 📊 Личный кабинет: история тренировок, время выполнения, % точности
- 👨‍👩‍👧 Родительский режим: просмотр прогресса ребёнка, уведомления

### 🤖 v2.0 — Интеграция ИИ (2–3 месяца после MVP)

- **Computer Vision анализ поз**:
  - Использование Google ML Kit Pose Detection (33 ключевые точки тела)
  - Сравнение позы пользователя с эталонной моделью пумсе в реальном времени
  - Оценка точности выполнения (углы суставов, баланс, траектория)
- 🔔 Мгновенная обратная связь: «рука выше», «нога шире», «корпус прямо»
- 📈 История улучшений: графики точности по движениям и сессиям

### 🚀 v3.0 — Расширенные функции

- 👥 Групповые челленджи между учениками школы
- 🏆 Система достижений и виртуальных наград (пояса, медали)
- 📹 Запись и сравнение «до/после» для мотивации
- 🌐 Интеграция с умными часами (биометрия: ЧСС, калории)

## 5. Архитектура ИИ-анализа пумсе

```
[Камера] 
    ↓
[ML Kit Pose Detection] → 33 ключевые точки скелета
    ↓
[Нормализация позы] → компенсация расстояния/угла
    ↓
[Валидатор пумсе] → сравнение с эталонной траекторией
    ↓
[Оценка параметров]
    ├── Угол колена в стойках (ап-коби, ап-чхаги)
    ├── Высота и траектория ударов ногами
    ├── Синхронизация рук/ног в переходах
    └── Баланс (центр масс)
    ↓
[Фидбек] → голосовые/визуальные подсказки + оценка (%)
```

> **Важно**: обработка видео происходит локально на устройстве. На сервер отправляются только анонимизированные скелетные данные для улучшения модели (с согласия родителей).

## 7. Юридические и этические аспекты

- ✅ **COPPA / GDPR-K** — обязательное согласие родителей на обработку данных детей до 13 лет
- ✅ **Безопасность видео** — локальная обработка ИИ без отправки видео на сервер
- ✅ **Лицензирование контента** — договоры с мастерами тхэквондо на демонстрацию пумсе
- ✅ **Отказ от ответственности** — предупреждение: «Приложение не заменяет тренера»
