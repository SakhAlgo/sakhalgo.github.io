# План создания сайта по пумсе на WordPress

## 📋 Общая стратегия

**Цель**: Создать информационный ресурс с видео и текстами по пумсе для учеников тхэквондо  
**Платформа**: WordPress (самый гибкий и масштабируемый вариант)  
**Бюджет**: Минимальный (бесплатные темы и плагины + недорогой хостинг)  
**Срок**: 2–3 недели до запуска

---

## 📅 Поэтапный план действий

---

### 1.3 Установка WordPress

**Вариант А: Автоматическая установка (рекомендуется)**

1. Зайдите в панель управления хостингом (ISPmanager, cPanel)
2. Найдите раздел «Сайты» → «WordPress»
3. Выберите домен и нажмите «Установить»
4. Укажите:
   - Название сайта: `Пумсе — обучение тхэквондо`
   - Логин администратора: `admin` (или ваш ник)
   - Пароль: **сложный** (сохраните!)
   - Email: ваш рабочий

**Вариант Б: Ручная установка**

1. Скачайте последнюю версию с [wordpress.org](https://wordpress.org/download/)
2. Загрузите файлы через FTP (FileZilla) в папку `public_html`
3. Создайте базу данных MySQL в панели хостинга
4. Запустите установку: `вашсайт.ru/wp-admin/install.php`

## 📌 Этап 4: Дизайн и оформление (День 4–5)

### 4.1 Настройка темы Astra

1. `Внешний вид` → `Настроить`
2. **Сайт Identity**:
   - Логотип: загрузите (200×60 пикселей)
   - Иконка сайта (favicon): 32×32 пиксели
3. **Header Builder**:
   - Меню слева, поиск справа
   - Прозрачный фон или цвет тхэквондо (#CC0000)
4. **Colors**:
   - Primary: `#CC0000` (красный тхэквондо)
   - Secondary: `#000000` (чёрный)
   - Background: `#FFFFFF`
   - Text: `#333333`
5. **Typography**:
   - Заголовки: `Roboto` или `Open Sans`
   - Текст: `Open Sans`
   - Размеры: заголовки 24–36px, текст 16–18px


   - **Текстовый блок**: Text Editor
   - **Карточки**: Posts или Custom HTML
   - **Карта пумсе**: Icon List или Custom HTML

## 📌 Этап 6: Техническая настройка (День 6–7)

### 6.1 Настройка постоянных ссылок (ЧПУ)

1. `Настройки` → `Постоянные ссылки`
2. Выберите: `Произвольно`
3. Введите: `/%category%/%postname%/`
4. Сохранить

**Результат:**
```
было: вашсайт.ru/?p=123
стало: вашсайт.ru/pumse/teguk-il-jang/
```

---

### 6.2 Настройка кэширования (WP Rocket)

1. Активируйте плагин
2. Базовые настройки:
   - ✅ Включить кэширование страниц
   - ✅ Ленивая загрузка изображений
   - ✅ Минификация CSS/JS
   - ✅ GZIP сжатие
3. Сохранить

---

### 6.3 Настройка изображений (Smush)

1. `Smush` → `Настройки`
2. Включите:
   - ✅ Супер-сжатие
   - ✅ Ленивая загрузка
   - ✅ Изменение размера больших изображений (макс 2000px)
3. Запустите массовое сжатие существующих изображений

---

### 6.4 Настройка резервного копирования (UpdraftPlus)

1. `Настройки` → `UpdraftPlus`
2. Настройте расписание:
   - База данных: ежедневно
   - Файлы: еженедельно
3. Выберите место хранения:
   - **Google Drive** (рекомендуется)
   - Dropbox
   - Локально (на хостинге)
4. Создайте первый бэкап вручную

---

### 6.5 Настройка безопасности

| Действие | Плагин/Метод |
|----------|--------------|
| Ограничение попыток входа | **Wordfence** или **Limit Login Attempts** |
| Скрыть версию WordPress | В `.htaccess` или через плагин |
| Отключить редактирование файлов | В `wp-config.php` добавить: `define('DISALLOW_FILE_EDIT', true);` |
| Сменить префикс таблиц БД | При установке или через плагин |

**Минимум:**
1. Установите **Wordfence Security**
2. Включите базовую защиту
3. Смените логин администратора с `admin` на что-то уникальное
