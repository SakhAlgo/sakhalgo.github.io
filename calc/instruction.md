## Онлайн калькулятор рецептов

### Быстрый старт

**1. Настройте шрифт**  
Кнопки **+** и **−** для изменения размера текста

**2. Введите название рецепта**

**3. Добавьте ингредиенты**
- Название продукта
- Количество (число)
- Единица измерения (г., кг., ст., ст. л., ч. л., по вкусу)
- Нажмите **"Добавить"**

Повторите для всех ингредиентов. Удалить — кнопка **×**

**4. Пересчитайте рецепт**
- Выберите: уменьшить или увеличить
- Введите коэффициент (например: 2 или 1.5)
- Нажмите **"Вычислить"**

**5. Скопируйте результат**  
Кнопка **"Копировать рецепт"**

---

### Пример

**Было** (4 порции):
- Мука — 400 г.
- Яйца — 4 шт.

**Уменьшить в 2 раза → Вычислить**

**Стало** (2 порции):
- Мука — 200 г.
- Яйца — 2 шт.

---

### Важно

✓ Ингредиенты **"по вкусу"** не пересчитываются  
✓ Заполните все поля перед добавлением  
✓ Нажмите "Вычислить" перед копированием

## Онлайн калькулятор рецептов

### Назначение приложения

Калькулятор рецептов позволяет автоматически пересчитывать количество ингредиентов в кулинарных рецептах при изменении количества порций. Это удобно, когда нужно увеличить или уменьшить рецепт в несколько раз.

---

## Начало работы

### 1. Настройка размера текста

В верхней части интерфейса расположены кнопки **"+"** и **"−"** для настройки размера шрифта:

- Нажмите **"+"** для увеличения размера текста
- Нажмите **"−"** для уменьшения размера текста
- Выбранный размер сохранится на время вашей сессии

### 2. Ввод названия рецепта

В поле **"Название рецепта"** введите название вашего блюда, например: "Борщ", "Шарлотка с яблоками", "Паста Карбонара".

---

## Добавление ингредиентов

### Шаг 1: Заполните данные об ингредиенте

Для каждого ингредиента заполните три поля:

1. **Название ингредиента** — введите название продукта (например: мука, сахар, яйца)
2. **Количество** — укажите числовое значение (например: 200, 1.5, 3)
3. **Единица измерения** — выберите из выпадающего списка:
   - **г.** (граммы)
   - **кг.** (килограммы)
   - **ст.** (стаканы)
   - **ст. л.** (столовые ложки)
   - **ч. л.** (чайные ложки)
   - **по вкусу** (для ингредиентов без точного количества)

### Шаг 2: Добавьте ингредиент в список

Нажмите кнопку **"Добавить"**. Ингредиент появится в списке ниже.

### Шаг 3: Повторите для всех ингредиентов

Добавьте все необходимые ингредиенты рецепта, повторяя шаги 1-2.

### Удаление ингредиента

Если вы добавили ингредиент по ошибке, нажмите кнопку **"×"** рядом с ним в списке.

---

## Масштабирование рецепта

### Шаг 1: Выберите тип масштабирования

В выпадающем списке выберите:

- **"Уменьшить во столько раз"** — если нужно уменьшить количество порций
- **"Увеличить во столько раз"** — если нужно увеличить количество порций

### Шаг 2: Укажите коэффициент

В числовое поле введите коэффициент масштабирования:

- Для уменьшения вдвое введите: **2**
- Для увеличения втрое введите: **3**
- Можно использовать дробные числа, например: **1.5**

### Шаг 3: Выполните расчёт

Нажмите кнопку **"Вычислить"**. Приложение автоматически пересчитает количество всех ингредиентов.

### Важно:

- Все числовые значения пересчитываются пропорционально
- Единицы измерения сохраняются
- Ингредиенты **"по вкусу"** остаются без изменений

---

## Просмотр и копирование результата

### Просмотр итогового рецепта

После нажатия **"Вычислить"** в разделе результатов отобразится:

- Название рецепта
- Полный список ингредиентов с пересчитанными количествами

Формат вывода:
```
[Название рецепта]

Ингредиент - количество единица измерения
Ингредиент - количество единица измерения
...
```

### Копирование рецепта

Нажмите кнопку **"Копировать рецепт"**, чтобы скопировать весь пересчитанный рецепт в буфер обмена. Затем вы сможете вставить его в любой текстовый редактор или мессенджер.

## Примеры использования

### Пример 1: Уменьшение рецепта

**Исходный рецепт** (на 4 порции):
- Мука — 400 г.
- Сахар — 200 г.
- Яйца — 4 шт.

**Действия:**
1. Добавьте все ингредиенты
2. Выберите "Уменьшить во столько раз"
3. Введите коэффициент: 2
4. Нажмите "Вычислить"

**Результат** (на 2 порции):
- Мука — 200 г.
- Сахар — 100 г.
- Яйца — 2 шт.

### Пример 2: Увеличение рецепта

**Исходный рецепт** (на 2 порции):
- Молоко — 250 мл
- Соль — по вкусу

**Действия:**
1. Добавьте ингредиенты
2. Выберите "Увеличить во столько раз"
3. Введите коэффициент: 3
4. Нажмите "Вычислить"

**Результат** (на 6 порций):
- Молоко — 750 мл
- Соль — по вкусу (не изменилось)

## Советы по использованию

✓ Вводите количество ингредиентов максимально точно для корректных расчётов

✓ Используйте единицу измерения **"по вкусу"** для специй, приправ и других ингредиентов без точного количества

✓ Проверяйте список ингредиентов перед масштабированием

✓ Сохраняйте пересчитанные рецепты, копируя их из приложения

✓ Настройте комфортный размер шрифта перед началом работы

---

## Устранение неполадок

**Проблема:** Кнопка "Добавить" не работает  
**Решение:** Убедитесь, что заполнены все три поля (название, количество, единица измерения)

**Проблема:** Неправильный результат расчёта  
**Решение:** Проверьте правильность введённых чисел и выбранный тип масштабирования (уменьшить/увеличить)

**Проблема:** Не копируется рецепт  
**Решение:** Убедитесь, что вы нажали кнопку "Вычислить" перед копированием
