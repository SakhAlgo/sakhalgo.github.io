ТЕХНИЧЕСКОЕ ЗАДАНИЕ

Веб-приложение "Онлайн калькулятор рецептов"

1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

Назначение: Веб-приложение для масштабирования кулинарных рецептов с автоматическим пересчетом количества ингредиентов.

Целевая аудитория: Домашние повара, кулинары, пользователи, которым нужно адаптировать рецепты под разное количество порций.

2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

2.1. Управление размером текста

Кнопки "+" и "-" для увеличения/уменьшения размера шрифта интерфейса
Сохранение выбранного размера в сессии пользователя
2.2. Добавление ингредиентов

Поля ввода:

Название ингредиента (текстовое поле)
Количество (числовое поле)
Единица измерения (выпадающий список):
г. (граммы)
кг. (килограммы)
ст. (стаканы)
ст. л. (столовые ложки)
ч. л. (чайные ложки)
по вкусу
Функционал:

Кнопка "Добавить" для сохранения ингредиента в список
Динамическое добавление ингредиентов без перезагрузки страницы
Отображение списка добавленных ингредиентов
Кнопка "×" (удалить) для каждого ингредиента в списке
2.3. Масштабирование рецепта

Функционал:

Выпадающий список с опциями:
"Уменьшить во столько раз"
"Увеличить во столько раз" (или другие варианты масштабирования)
Поле для ввода коэффициента масштабирования (число)
Кнопка "Вычислить" для применения масштабирования
Логика расчета:

Пропорциональное изменение всех числовых значений ингредиентов
Сохранение единиц измерения
Ингредиенты "по вкусу" остаются без изменений
2.4. Управление рецептом

Поле для ввода названия рецепта
Отображение итогового рецепта с пересчитанными значениями
Кнопка копирования рецепта в буфер обмена
2.5. Отображение результата

Формат вывода:

Название рецепта
Ингредиент - количество единица измерения
(для всех ингредиентов)
