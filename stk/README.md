# 📡 Тест-Центр

Современная система для тестирования сотрудников с поддержкой нескольких разделов, пошаговым прохождением, таймером и сохранением прогресса.

## 🚀 Возможности

- **Три раздела:** Кабельное ТВ, Интернет, Домофоны
- **Поддержка изображений:** В теории и в вариантах ответов
- **Гибкая система вопросов:** Одиночный (radio) и множественный (checkbox) выбор
- **Пошаговое прохождение:** Вопросы отображаются по одному с навигацией
- **Теория:** Полная теория по каждому разделу с изображениями
- **Таймер:** Ограничение времени (30 минут), автоматическое завершение
- **Сохранение состояния:** Автосохранение в localStorage
- **Адаптивный дизайн:** Работает на всех устройствах
- **Тестирование:** Встроенные тесты для проверки работоспособности

## 📋 Оценка результатов

## 🛠️ Как запустить

1. **Скачайте все файлы** в папку `test-system`
2. **Откройте `index.html`** в браузере
3. **Для проверки** откройте `tests/tests.html`

## 📝 Как добавлять вопросы

### Вопрос с текстовыми ответами

В файле `js/data/data-*.js` добавьте:

```javascript
{
    id: 11,
    type: 'radio',          // или 'checkbox'
    question: 'Ваш вопрос?',
    options: [
        'Вариант А',
        'Вариант Б',
        'Вариант В',
        'Вариант Г'
    ],
    correct: [0]            // Индексы правильных ответов
}

Вопрос с изображениями в ответах
javascript
{
    id: 12,
    type: 'radio',
    question: 'Выберите правильный тип разъёма?',
    options: [
        { text: 'RCA', image: 'images/tv/rca.jpg' },
        { text: 'F-разъем', image: 'images/tv/f-connector.jpg' },
        { text: 'BNC', image: 'images/tv/bnc.jpg' }
    ],
    correct: [1]
}
Как добавлять изображения в теорию
В теории используйте плейсхолдер:

text
[IMAGE:images/tv/scheme.jpg]
Изображение будет автоматически вставлено в теорию.
