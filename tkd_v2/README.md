# Пхумсе Тхэквондо - Обучение

Веб-сайт для изучения Пхумсе (форм) в тхэквондо, представляющий собой интерактивное обучающее пособие с видео-демонстрациями различных форм для разных уровней поясов.

## 📋 Описание проекта

Этот веб-сайт создан для спортсменов, занимающихся тхэквондо, которые хотят изучить и практиковать различные формы (пхумсе). Проект включает в себя:

- Подробное описание каждой формы (пхумсе) от белого до черного пояса
- Видео-демонстрации выполнения форм
- Информацию о системе поясов в тхэквондо
- Интерактивную навигацию по уровням подготовки
- Адаптивный дизайн для использования на различных устройствах

## ✨ Особенности

- **Интерактивная навигация**: Легко переключайтесь между различными уровнями поясов
- **Видео-уроки**: Видео-демонстрации выполнения форм с разных ракурсов
- **Адаптивный дизайн**: Оптимизирован для просмотра на мобильных устройствах и планшетах
- **Анимации и эффекты**: Плавные переходы и анимации при прокрутке
- **Слайдеры Swiper**: Удобный просмотр нескольких видео для каждой формы
- **Информация о поясах**: Подробное объяснение системы поясов в тхэквондо

## 🛠️ Технологии

- **HTML5**: Семантическая разметка
- **CSS3**: Адаптивный дизайн, градиенты, анимации
- **JavaScript**: Интерактивность, анимации при прокрутке, слайдеры
- **Swiper.js**: Библиотека для создания слайдеров
- **Bootstrap**: Адаптивная сетка (при необходимости)

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/username/tkd-poomsae.git
   ```

2. Перейдите в директорию проекта:
   ```bash
   cd tkd-poomsae
   ```

3. Откройте файл `index.html` в вашем веб-браузере

Альтернативно, вы можете использовать локальный сервер для разработки:
   ```bash
   # Если установлен Python
   python -m http.server 8000
   
   # Или если установлен Live Server (VS Code extension)
   # Вызовите команду "Live Server: Open with Live Server"
   ```

## 🎯 Функциональность

- **Навигация по уровням**: Быстрый переход к нужному уровню пояса
