# Промпт для создания аналогичного веб-приложения

## Общее описание
Создайте веб-приложение, подобное приложению "Пхумсе Тхэквондо - Обучение". Это должно быть образовательное веб-приложение, посвященное какой-либо спортивной или образовательной теме, с видеоуроками, информацией о прогрессии и интерактивными элементами.

## Основные требования

### 1. Тематика
Выберите тему для вашего приложения (например, йога, карате, программирование, музыка, кулинария и т.д.). Приложение должно быть образовательным и предоставлять контент в виде видеоуроков или других материалов.

### 2. Структура
- Создайте одностраничное приложение (SPA) с навигацией по якорным ссылкам
- Используйте семантические HTML-элементы
- Обеспечьте логическую структуру контента

### 3. Дизайн
- Современный, адаптивный дизайн с использованием градиентов
- Анимации и плавные переходы между элементами
- Визуальная иерархия контента
- Поддержка различных размеров экранов (мобильные, планшеты, десктопы)

### 4. Функциональность
- Навигационное меню с иконками или символами, представляющими различные уровни или категории
- Адаптивное гамбургер-меню для мобильных устройств
- Слайдеры для отображения контента (видео, изображений и т.д.)
- Анимации при прокрутке (Intersection Observer API)
- Плавная прокрутка к якорям
- Эффекты при наведении и взаимодействии с элементами
- Кнопка "наверх" для удобства навигации
- Поддержка видео с различных источников

### 5. Технологии
- HTML5
- CSS3 (с использованием переменных, градиентов, анимаций)
- JavaScript (ES6+) для интерактивности
- Библиотека Swiper для создания слайдеров
- Адаптивная верстка с использованием медиа-запросов

### 6. Контент
- Информационные разделы, соответствующие выбранной теме
- Видеоуроки или другие обучающие материалы
- Описание уровней или категорий
- Философия или объяснение темы приложения

## Дополнительные возможности
- Возможность добавления новых уроков или материалов
- Система прогресса пользователя (по желанию)
- Возможность комментирования или обсуждения материалов (по желанию)
- Интеграция с социальными сетями (по желанию)

## Требования к файловой структуре
- index.html - главная страница приложения
- styles.css - файл стилей
- script.js - файл скриптов
- папка img/ - для хранения изображений
- (по необходимости) другие файлы и папки

## Технические требования

### HTML
- Использование семантических элементов (header, nav, section, footer и т.д.)
- Корректная вложенность и структура документа
- Подключение внешних библиотек через CDN
- Оптимизация для SEO (правильные заголовки, meta-теги)
- Поддержка русского и английского языков (по желанию)

### CSS
- Использование CSS-переменных для управления цветами и стилями
- Адаптивная верстка с использованием flexbox и grid
- Медиа-запросы для поддержки различных размеров экранов
- Анимации и переходы с использованием CSS
- Организация кода по методологии (например, БЭМ)
- Минификация CSS для продакшена (по желанию)

### JavaScript
- Современные возможности ES6+ (стрелочные функции, деструктуризация, модули и т.д.)
- Использование Swiper API для слайдеров
- Intersection Observer API для анимаций при прокрутке
- DOM манипуляции без использования jQuery
- Обработка событий и асинхронные операции
- Оптимизация производительности (ленивая загрузка, debounce и т.д.)
- Обработка ошибок и исключений

### Производительность
- Оптимизация изображений и видео
- Ленивая загрузка контента
- Минификация и объединение файлов (по желанию)
- Кэширование ресурсов
- Оптимизация времени загрузки страницы

### Совместимость
- Поддержка современных браузеров (Chrome, Firefox, Safari, Edge)
- Проверка корректной работы на мобильных устройствах
- Соответствие стандартам W3C

## Особенности реализации
- Использование CSS-переменных для управления цветами и стилями
- Адаптивная верстка с учетом разных размеров экранов
- Оптимизация производительности (ленивая загрузка видео, эффективные анимации)
- Обработка ошибок (например, при загрузке видео)
- Поддержка современных браузеров
- Создание пользовательских эффектов и анимаций
- Реализация плавной навигации и взаимодействия
- Обеспечение доступности (accessibility) интерфейса

## Структура файлов и содержимое

### index.html
- Основная структура страницы с шапкой, навигацией, контентными секциями и футером
- Подключение стилей и скриптов
- Семантические элементы для лучшей структуры
- Навигационное меню с якорными ссылками
- Секции для каждого уровня/категории с видео-контентом
- Слайдеры Swiper для отображения нескольких видео в одной категории
- Элементы для анимаций при прокрутке
- Кнопка "наверх"

### styles.css
- CSS-переменные для управления цветами и стилями
- Сброс стилей и базовые стили
- Стили для навигации (включая адаптивное гамбургер-меню)
- Стили для основных секций (герой, пояса, формы, фристайл, футер)
- Стили для слайдеров и видео-контейнеров
- Анимации и переходы
- Адаптивные стили для разных размеров экранов
- Стили для эффектов при наведении

### script.js
- Инициализация слайдера Swiper
- Обработка событий для гамбургер-меню
- Логика плавной прокрутки к якорям
- Анимации при прокрутке с использованием Intersection Observer API
- Обработка событий прокрутки для изменения навбара
- Ленивая загрузка iframe для видео
- Эффекты при наведении на элементы
- Обработка ошибок загрузки видео
- Реализация кнопки "наверх"
- Дополнительные интерактивные элементы (ripple эффект и т.д.)

### img/
- Изображения поясов для навигации
- Иконки и другие графические элементы
- Изображения могут быть в форматах PNG, SVG, JPG
